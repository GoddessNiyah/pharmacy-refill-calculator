# Pharmacy Refill Calculator

A simple web-based pharmacy refill date calculator built with HTML, CSS, and JavaScript.

## Features

- Select a prescription fill date
- Enter a custom days supply
- Quick-select 30, 60, or 90 days
- Calculate the estimated refill date
- Show an estimated earliest refill date
- Validate missing or invalid input
- Mobile-friendly responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## 🔗 Live Website

[View the Pharmacy Refill Calculator](https://goddessniyah.github.io)

## Disclaimer

Estimated dates only. Actual refill eligibility may vary based on medication, insurance, pharmacy policy, and applicable laws.
